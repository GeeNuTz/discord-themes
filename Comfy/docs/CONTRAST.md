Generated by `npm run report` from `ComfyDeep.theme.css` and `ComfyDeep-Revenge.json`.

## How every number is produced

Translucent surfaces are composited over the brightest backdrop pixel the build can
produce, and text is measured against the surface it actually sits on. That is the
worse case for light text: if it passes here, it passes anywhere on screen.

- The stylesheet samples the real `--background-image` declaration, so the bound moves with
  the gradient.
- The Revenge manifest cannot paint a gradient: its surfaces are opaque hex values composited
  over that same measured peak, which is the worst case for light text.

## Colours that must not appear

Each of these would mean palette leakage - a sibling theme or Discord's own blurple
surviving into a teal build. `npm test` fails if any appears in a declaration.

| Value | Why it is a bug |
|---|---|
| `#5865f2` | Discord blurple: a brand-* ramp was left unmapped |
| `#8957ff` | Aetheris violet: the sibling theme leaked in |
| `#9360f0` | Aetheris accent: the sibling theme leaked in |
| `#080228` | Aetheris canvas: the sibling theme leaked in |
| `#7150eb` | the old purple "red": danger lost its meaning |

## Reproducing

```bash
cd repo
npm test            # 23 checks across both artifacts
npm run report      # rewrites this file
```

Dependency-free: `test/color.js` (WCAG math), `test/css.js` (stylesheet + var()
resolution), `test/gradient.js` (samples the background, gradient or wallpaper),
`test/palette.js` (resolves colours over the measured backdrop), `test/spec.js`
(the contract: pairs, floors, legacy values).
