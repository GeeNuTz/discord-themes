# Credits

The desktop builds are customisations of ClearVision v7, imported at runtime — they are not
standalone themes.

| Component | What it provides | Source |
|---|---|---|
| ClearVision v7 | base desktop theme (imported, not bundled) | <https://github.com/ClearVision/ClearVision-v7> |
| Vesktop / Vencord | desktop client targets | <https://vesktop.vencord.dev> · <https://vencord.dev> |
| Revenge | mobile client target | <https://revenge-mod.dev> |

Palette overrides and the Revenge manifests are part of this repository.
